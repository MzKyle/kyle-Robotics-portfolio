# Kyle Wang Robotics Portfolio

Personal robotics software engineering portfolio built with Next.js, Vinext,
React, Tailwind CSS, and the Cloudflare Workers runtime.

The site presents project case studies, experience, resume material, and
technical writing for job applications.

## Prerequisites

- Node.js `>=22.13.0`
- npm
- Linux/macOS shell environment for the helper scripts

Use the pinned local version when a Node version manager is available:

```bash
nvm use
```

## Development

```bash
npm ci
npm run dev
```

Common checks:

```bash
npm run lint
npm run build
npm test
```

`npm run build` runs `vinext build` and validates the generated Cloudflare
Worker artifact. `npm test` builds the site and verifies the rendered homepage
metadata from the Worker entry.

## Cloudflare Deployment

The project targets Cloudflare Workers with static assets generated by Vinext.
Connect the GitHub repository to Cloudflare Workers & Pages and use:

- Production branch: `main`
- Build command: `npm ci && npm run build`
- Deploy command: `npx wrangler deploy`
- Preview deploy command: `npx wrangler versions upload`
- Build variable: `NODE_VERSION=22.13.0`

The initial public entry point should use the default `*.workers.dev` domain.
Custom domains can be added later from Cloudflare once DNS is ready.

## Project Shape

- `app/`: Next.js app routes and page content
- `components/`: shared UI components
- `lib/`: portfolio data and CSDN article integration
- `public/`: resume PDF and image assets
- `worker/`: Cloudflare Worker entry point
- `scripts/`: build and artifact validation helpers

Generated output and runtime state such as `dist/`, `.vinext/`, `.wrangler/`,
`.openai/`, and `.sites-runtime/` are intentionally ignored.
