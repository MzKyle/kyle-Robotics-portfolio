Portfolio Sans SC is a self-hosted character subset of Noto Sans SC from the
Google Fonts repository, renamed for this portfolio. It retains variable
weights and the characters used in the site's source and technical essay.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
License: SIL Open Font License 1.1, reproduced in OFL-NotoSansSC.txt.

Geist handles Latin text; this font handles Chinese consistently across devices.
New characters outside the subset use the next system font in the CSS stack.
